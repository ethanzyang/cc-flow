---
name: stats
description: 看流程度量（workflow §7）：最近 N 天的 PR 从首个提交到合并的时长、PR 非测试代码行数、审阅轮数、只改文档的提交占比、上线后 48 小时内的修复。用户问「最近效率怎么样」「流程快了吗」或定期复盘时用。
---

跑：

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/stats.sh" "<项目目录>" [--days 14]
```

需要 `gh` 已登录才能拿到 PR 数据；没有 gh 时只出 git 能算的几项。

把输出整理成 3–5 行给用户：哪几项达标、哪几项没达标，没达标的最可能原因（看最慢 / 最大的几个 PR 各是什么）。
目标见 workflow §7：双向门当天上线；PR 中位数非测试代码 ≤400 行；每个 PR 审阅 ≤1 轮；只改文档的提交 <15%。
不达标且原因是流程本身 → 按 workflow §7 当天改流程。
